# Documentación del harness

Estos archivos definen **cómo funciona el arnés** — workflow, especificaciones, progreso y metadatos.

No requieren personalización al adaptar el harness a un proyecto concreto. Modifícalos solo si estás extendiendo o ajustando el propio harness.

| Archivo | Propósito |
|---------|-----------|
| `workflow.md` | Flujo de Work Items, estados y transiciones. |
| `specs.md` | Spec Driven Development y formatos de planificación. |
| `progress.md` | Sistema de progreso y plantillas de `progress/`. |
| `meta.md` | Estructura y significado de `meta.json`. |
